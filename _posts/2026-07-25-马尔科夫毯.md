一个“膜”（边界）不是被预先设计或放置的，它如何能从底层变量间的局部耦合中自然涌现出来？

为此，设定一个最小的三变量系统，并逐步证明：当变量间的依赖关系满足特定条件时，中间变量会自然成为一条“统计隔离带”，将一侧与另一侧隔开。

膜的涌现，就是关系稳定化的时空签名。

## 1.1 问题设置：最小系统与因果链

我们考察一个由**三个二元变量**构成的最小系统：

- **A**：外部变量（环境）
- **B**：边界变量（潜在的“膜”）
- **C**：内部变量（系统内部状态）

设定它们之间的**单向因果链**为：

$$
A \rightarrow B \rightarrow C
$$

即 A 影响 B，B 影响 C，而 **A 与 C 之间没有直接连接**。

该系统的联合概率分布可分解为：

$$
P(A, B, C) = P(A) \times P(B \mid A) \times P(C \mid B)
$$

如果上述分解成立，则**给定 B 时，A 与 C 条件独立**，B 自然成为一层“马尔可夫毯”。

我们在此要演示的是：**这层“毯子”并非预先植入的结构，而是通过局部耦合关系在统计上自然涌现的。**

---

## 1.2 第一组参数：先看条件独立成立的样子

首先设：

- $P(A=1) = 0.5$
- $P(B=1 \mid A=1) = 0.9,\quad P(B=1 \mid A=0) = 0.1$
- $P(C=1 \mid B=1) = 0.9,\quad P(C=1 \mid B=0) = 0.1$

联合概率表（8种状态）：

|  A  |  B  |  C  |             $P(A,B,C)$              |
| :-: | :-: | :-: | :---------------------------------: |
|  0  |  0  |  0  | $0.5 \times 0.9 \times 0.9 = 0.405$ |
|  0  |  0  |  1  | $0.5 \times 0.9 \times 0.1 = 0.045$ |
|  0  |  1  |  0  | $0.5 \times 0.1 \times 0.1 = 0.005$ |
|  0  |  1  |  1  | $0.5 \times 0.1 \times 0.9 = 0.045$ |
|  1  |  0  |  0  | $0.5 \times 0.1 \times 0.9 = 0.045$ |
|  1  |  0  |  1  | $0.5 \times 0.1 \times 0.1 = 0.005$ |
|  1  |  1  |  0  | $0.5 \times 0.9 \times 0.1 = 0.045$ |
|  1  |  1  |  1  | $0.5 \times 0.9 \times 0.9 = 0.405$ |

验证条件独立性（给定 $B=1$）：

- $P(B=1) = 0.005 + 0.045 + 0.045 + 0.405 = 0.5$
- $P(A=1, C=1 \mid B=1) = 0.405 / 0.5 = 0.81$
- $P(A=1 \mid B=1) = (0.045 + 0.405) / 0.5 = 0.45 / 0.5 = 0.9$
- $P(C=1 \mid B=1) = (0.045 + 0.405) / 0.5 = 0.9$

检查：$P(A=1 \mid B=1) \times P(C=1 \mid B=1) = 0.9 \times 0.9 = 0.81$

两端相等，条件独立成立。这一组数值太整齐（两处条件概率都取 0.9 / 0.1），所以看上去像是被安排好的。换一组不那么整齐的数值，看同一个结构还在不在。

## 1.3 第二组参数：换掉数值，结构仍然成立

保留相同的逻辑形式，只改数值：

- $P(A=1) = 0.5$
- $P(B=1 \mid A=1) = 0.9,\quad P(B=1 \mid A=0) = 0.1$
- $P(C=1 \mid B=1) = 0.8,\quad P(C=1 \mid B=0) = 0.2$

联合概率表：

|  A  |  B  |  C  |             $P(A,B,C)$             |
| :-: | :-: | :-: | :--------------------------------: |
|  0  |  0  |  0  | $0.5 \times 0.9 \times 0.8 = 0.36$ |
|  0  |  0  |  1  | $0.5 \times 0.9 \times 0.2 = 0.09$ |
|  0  |  1  |  0  | $0.5 \times 0.1 \times 0.8 = 0.04$ |
|  0  |  1  |  1  | $0.5 \times 0.1 \times 0.2 = 0.01$ |
|  1  |  0  |  0  | $0.5 \times 0.1 \times 0.8 = 0.04$ |
|  1  |  0  |  1  | $0.5 \times 0.1 \times 0.2 = 0.01$ |
|  1  |  1  |  0  | $0.5 \times 0.9 \times 0.8 = 0.36$ |
|  1  |  1  |  1  | $0.5 \times 0.9 \times 0.2 = 0.09$ |

验证给定 $B=1$ 的条件独立性：

- $P(B=1) = 0.04 + 0.01 + 0.36 + 0.09 = 0.5$
- $P(A=1, C=1 \mid B=1) = 0.09 / 0.5 = 0.18$
- $P(A=1 \mid B=1) = (0.36 + 0.09) / 0.5 = 0.45 / 0.5 = 0.9$
- $P(C=1 \mid B=1) = (0.01 + 0.09) / 0.5 = 0.10 / 0.5 = 0.2$
- 乘积：$0.9 \times 0.2 = 0.18$ ✅

数值全换了，条件独立照样成立。B 仍然是 A 与 C 之间的统计隔离带。

## 1.4 从“数值验证”到“本质理解”

两组不同的参数给出的共同点，不在数字本身，而在**条件概率分解里不存在绕开 B 的路径**：

> $P(C \mid B)$ 中未出现 A，意味着 C 不直接“知道” A。A 对 C 的全部影响，必须经由 B 传导。

这就是马尔可夫毯的数学本质：**给定边界变量后，内部与外部在统计上相互独立。**

反过来说，只要 C 的分布里混进了 A——比如写成 $P(C \mid A, B)$——独立性立刻破掉，B 就不再是毯子，只是一根普通的中间管道。可以把它写成一句判据：一个变量是不是边界，取决于它出现在分解式的哪个位置，而不取决于它取什么值。

由此，B 呈现两种动态状态：

| 状态         | 方向  | 功能            | 数值体现                |
| :----------- | :---- | :-------------- | :---------------------- |
| **感受状态** | 外→内 | B 接收 A 的信号 | $P(B=1 \mid A=1) = 0.9$ |
| **主动状态** | 内→外 | B 调节 C 的状态 | $P(C=1 \mid B=1) = 0.8$ |

B 因此不是一堵“墙”，而是一个**有选择渗透性的活界面**，支持持续的感知-行动循环。

## 1.5 从数学演示到元公理 0

将上述演示置于“交叉视域”的纲领之下，它与元公理 0 之间形成精确的对应关系：

| 数学演示中的操作                                             | 对应的元公理 0 命题                                                    |
| :----------------------------------------------------------- | :--------------------------------------------------------------------- |
| 变量 A、B、C 初始时无预设边界                                | 实体并非先于关系存在                                                   |
| 通过设定 $P(C \mid B)$ 而非 $P(C \mid A,B)$ 来建立条件独立性 | 边界（B）的“毯子”属性是由**关系分解方式**决定的，而非 B 自身的内在属性 |
| 验证 $P(A,C\|B) = P(A\|B)P(C\|B)$ 成立                       | 关系网络在统计上实现了“隔离”，从而识别出“内部”与“外部”                 |
| B 既能感受 A 又能调节 C                                      | 边界不是死隔断，而是活的“感知-行动”界面                                |

**结论**：

> 马尔可夫毯不是被“放置”在系统中的实体，而是在关系网络的持续局部耦合中，通过条件独立性**自然涌现出的统计结构**。它使“内部”与“外部”变得可识别，但它的存在本身依然取决于底层交互关系的模式——而不是反过来。

这个三变量演示，因此构成对元公理 0 的一个**可数值验证的数学旁证**：关系的结构先于结构的命名，膜的涌现先于膜的定义。
